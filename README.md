# Norsk

## Norsk Kort — виджет для изучения норвежского на macOS

Приложение с виджетом для рабочего стола macOS. Виджет по очереди показывает карточки:

1. **норвежская фраза** (bokmål),
2. **перевод на русский**,
3. **пример употребления** с переводом и короткой заметкой: формы глагола, род, буквальный перевод идиомы.

Типы карточек:

| Категория | По-норвежски | Пример |
|---|---|---|
| Слова | Ord | koselig, en dugnad, å orke |
| Фразовые глаголы | Partikkelverb | å gi opp, å finne ut, å se fram til |
| Идиомы | Idiomer | Det er ingen ku på isen |
| Фразы | Fraser | Takk for sist! |
| Выражения | Uttrykk | etter hvert, i hvert fall |
| Пословицы | Ordtak | Borte bra, men hjemme best |

### Что умеет

**Виджет** (маленький, средний, большой):
- сам меняет карточку раз в 15 минут, 30 минут, час, 3 часа или день;
- кнопка **«Дальше»** сразу переключает на следующую карточку;
- **режим тренировки** скрывает перевод, пока не нажмёте **«Перевод»**;
- можно выбрать одну категорию, например только идиомы;
- клик по виджету открывает эту карточку в приложении.

**Приложение:**
- каталог всех карточек с поиском по-норвежски и по-русски;
- режим **«Тренировка»**: пробел открывает перевод, → переходит к следующей карточке;
- озвучка фраз и примеров системным норвежским голосом (🔊).

### Как собрать

Нужны macOS 14 Sonoma или новее, Xcode 15+ и [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```bash
brew install xcodegen
xcodegen generate
open NorskKort.xcodeproj
```

1. Укажите свой Team ID один раз, **до** `xcodegen generate`: скопируйте `Config/Local.xcconfig.example` в `Config/Local.xcconfig` и впишите туда свой ID. Подойдёт бесплатный Apple ID. Файл не попадает в git, а Team автоматически применяется к приложению и виджету: обе цели должны быть подписаны одинаково, иначе Xcode выдаст ошибку «Embedded binary is not signed with the same certificate». Без подписи macOS не показывает виджет.
2. Запустите схему **NorskKort** (⌘R).
3. Правый клик по рабочему столу → **«Изменить виджеты…»** → найдите **«Норвежские карточки»** и перетащите виджет на стол.
4. Чтобы выбрать категорию, интервал или режим тренировки: правый клик по виджету → **«Изменить виджет»**.

Для озвучки может понадобиться норвежский голос: Системные настройки → Универсальный доступ → Устная речь → Системный голос → Управление голосами → Norsk.

### Как добавить карточки

Все карточки лежат в [`Shared/cards.json`](Shared/cards.json):

```json
{
  "id": "id-ingen-ku-pa-isen",
  "category": "idiom",
  "norwegian": "Det er ingen ku på isen.",
  "russian": "Всё в порядке, волноваться не о чем.",
  "example": "Slapp av, det er ingen ku på isen – vi rekker toget.",
  "exampleTranslation": "Расслабься, всё в порядке – мы успеваем на поезд.",
  "note": "Букв.: «На льду нет коровы»."
}
```

- `category` — одно из значений `word`, `phrasalVerb`, `idiom`, `phrase`, `expression`, `proverb`;
- `id` должен быть уникальным;
- `note` можно не заполнять: `null`.

### Структура

```
project.yml          — описание Xcode-проекта для XcodeGen
Shared/              — общие для приложения и виджета модель и карточки
NorskKort/           — приложение: каталог, тренировка, озвучка
NorskKortWidget/     — виджет WidgetKit и интерактивные кнопки (App Intents)
scripts/make_icon.py — рисует иконку приложения (python3 scripts/make_icon.py)
```
